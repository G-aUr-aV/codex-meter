# Public source boundary

This repository starts with a reviewed source snapshot. Previous development history, installation-specific QA screenshots, live endpoint records and operational reports are excluded. The original development history is retained privately by the operator.

Only source, synthetic fixtures, generic setup examples and required application assets belong here. Keep private vaults, financial records, learning libraries, account credentials, session logs, generated usage reports, database exports and runtime configuration outside Git.

The initial publication was scanned with Gitleaks 8.30.1. Pattern scanning is one review layer; it does not replace reviewing future changes and attachments before pushing.
